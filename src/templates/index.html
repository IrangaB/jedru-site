Security

Built so one licence means one user

One active session per account

Signing in on a second device signs the first one out, with a prompt so the real owner always wins.

Trusted devices

Each device is fingerprinted and must be confirmed by email code the first time. You can see and revoke devices from the portal.

Signed entitlements

Licences are cryptographically signed by Jedru and verified by every product on every request. They cannot be edited or forged.

Code stays on our servers

Products run server-side; your browser only receives rendered screens. Installed agents are signed and bound to the machine they were activated on.
