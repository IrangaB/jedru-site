# jedru.com — marketing site

Static site generated by `build.py` (Jinja2) into `dist/`, hosted on Cloudflare Pages (project `jedru`).

```
python3 build.py            # -> dist/ (absolute links, for Cloudflare Pages)
python3 build.py --relative # preview build with relative links
```

## Deploying (the contact/quote form needs Pages Functions)

Cloudflare Pages **ignores `functions/` when the site is uploaded by drag-and-drop in the dashboard**, so the
form would fail (the page then falls back to opening the visitor's email app). Deploy one of these two ways:

**A. Connect the GitHub repo (recommended — every `git push` deploys):**
Cloudflare → Workers & Pages → jedru → Settings → Builds → connect `IrangaB/jedru-site`:
build command `pip install -r requirements.txt && python build.py`, build output directory `dist`,
root directory `/`. Functions are picked up from `functions/` automatically. Add the secret `RESEND_API_KEY`
under Settings → Variables and Secrets (Production).


## Pricing

Three USD plans per product, defined once in `build.py` → `TIERS` (Entry / Mid-market / Premium, monthly and a
fixed annual price). The same numbers live in the portal's `seed_products` command; change both together.

## Contact form → support@jedru.com (Cloudflare Pages Function + Resend)

`src/functions/api/contact.js` is copied to `dist/functions/api/contact.js`; Cloudflare runs it at
`POST https://jedru.com/api/contact` and the form on `/company/#contact` posts there. One-time setup:

1. https://resend.com → sign up (free tier: 3,000 emails/month) → **Domains → Add domain** `jedru.com`.
   Resend shows 3 DNS records (DKIM TXT, SPF/MX for `send.jedru.com`, optional DMARC). Add them in Cloudflare
   → DNS (set the MX/TXT records to **DNS only**, not proxied). Click *Verify* in Resend.
2. Resend → **API Keys → Create** (Sending access, domain jedru.com). Copy the key once.
3. Cloudflare → Workers & Pages → `jedru` → **Settings → Variables and Secrets → Add**:
   `RESEND_API_KEY` = the key (type *Secret*, Production). Optional: `CONTACT_TO` (default `support@jedru.com`),
   `CONTACT_FROM` (default `Jedru Website <website@jedru.com>`; the domain must be the verified one).
4. Re-deploy the site (upload `dist/` again) so the function and the variables are live.
5. Test: fill the form on jedru.com/company/#contact. The email arrives at support@jedru.com with every field
   (name, company, email, product, message, country/IP, time) and **Reply-To** set to the sender.

The function validates fields, drops spam via a hidden honeypot field, rate-limits 5 messages / 10 min per IP, and
never exposes the API key to the browser. `support@jedru.com` itself must exist as a mailbox (e.g. Cloudflare Email
Routing → forward support@jedru.com to your Gmail; free).
